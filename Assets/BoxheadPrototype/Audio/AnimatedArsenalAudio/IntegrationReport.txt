Audio package installed in Unity

Coverage audit: the current 17 weapons had populated sound banks, but the ArsenalAudio family aliases did not provide correct dedicated sounds for the new mechanisms. The crossbow, grenade launcher, dual break-action shotguns and rotary minigun required distinct sources; melee needed swing/thrust/contact events. The completed package is now connected to the saved Boxhead scene and runtime event hooks.

Deliverables: Mapping.json gives every catalogue ID/name and event path. Production.json gives 43 newly downloaded ElevenLabs takes, full prompts, download paths, output names and processing limits. Validation.json records archived source hashes and basic preparation. PackageChecks.json verifies all 91 referenced runtime clips, 17 weapons, 16 repeated-fire checks, reload duration bounds and independent source hashes for Beretta/heavy-pistol/jump/landing variations.

Use the processed shot_variations in Mapping.json. Its events.shot points to the first processed variation. The simple named source-staging WAVs preserve preparation inputs; they do not all include the final bass treatment. Beretta id12 and Heavy Pistol id13 have three independent ElevenLabs shot takes each. Other shot variants use subtle rate changes from a single source, explicitly documented; they are not claimed as independent generations. Source archives remain under Sources/.

Original sound design adds a short parallel low-frequency pressure layer and controlled saturation to firearm variants only, with peak normalization and overlap headroom. Shotgun bodies are broad, heavy-pistol bodies deeper, SMG/minigun bodies shorter. Crossbow and melee receive no artificial firearm concussion. These are new original effects, not copied Bodycam recordings. Dynamic early reflections and warehouse reverb must remain separate. Keep user master and SFX controls.

Reuse is documented in Mapping.json sources: belt-fed LMG uses the existing M60-family discharge/belt/charging recordings; Boomstick uses existing pump-shotgun discharge/shell/pump recordings; scoped bolt-action sniper uses existing Scout-family sources; P9 uses existing 9mm sidearm sources; Beretta reuses suitable 9mm magazine/slide handling but has new shots; dual SMG uses existing 9mm open-bolt discharge/action with a new paired straight-magazine reload. Talon/heavy-pistol slide handling, closed-bolt rifle charging and Persuader open-bolt action use existing matching mechanism-class foley. These handling recordings are shared, not new weapon-specific takes. Persuader and Heavy Rifle assessments are recorded as model-family/artistic inference rather than exact manufacturer claims.

Integration requirements:
- Preserve the catalogue order 0..16. Heavy Pistol/Deagle sound goes to id13, Beretta to id12. Use turret path from the manifest.
- Fire once per actual discharge. Use short variations for automatic fire; no continuous firing loop survives trigger release, reload, empty magazine or weapon switch.
- Minigun: distinct feed latch, reload and motor start/stop. Start motor once at firing onset, stop at release/reload/empty/switch. Motor assets must not replay on every shot.
- Grenade: launch at projectile spawn; spatial explosion at detonation, replacing the current scrap placeholder. Launch and explosion must not play simultaneously at firing.
- Crossbow: string/bolt release at attack, cock/load during reload, hard impact at environment contact, flesh puncture at enemy contact. Do not apply firearm room-shot tail to string/motion events.
- Knife/pitchfork: swing or stab follows the animation; contact impact plays only on confirmed hit. Melee has no reload sound. Update any legacy check requiring non-null gunshot/reload for all 17 banks accordingly.
- Full Minigun/Grenade/Sawnoff/Crossbow reload sources already include mechanical closing/loading. Do not duplicate their close by blindly playing standalone action at reload end; standalone handling events have separate purpose.
- Movement: Jump_01..03 at existing jumpSound takeoff trigger (.24 gain), Landing_01..03 at existing landingSound ground-transition trigger (.38 gain). These are three independent source takes per family. Default fields can use _01; variation selection can rotate all three. No cartoon boing, baked long hall or voice/breath requested in the source prompts.
- New runtime WAV importer metadata preserves existing GUIDs and sets PCM, preload, mono, normalize off and 48k override. Unity import and Play-mode decoding checks have passed. Sources remain PCM16 48kHz; the active WebGL target uses Unity's 44.1kHz serialized import rate. Subjective perceived loudness remains a listening assessment.

Run PrepareAudio.py, BuildMapping.py, VerifyAudio.py in order to reproduce this package from archived sources/downloads. Scripts write only inside this folder. Numerical verification does not establish subjective listening quality or in-game integration.
